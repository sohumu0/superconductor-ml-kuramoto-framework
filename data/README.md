# Data

This directory holds the datasets used in the analysis. The CSV files are too large for Git and must be obtained separately.

## UCI / SuperCon (Hamidieh 2018)

Place the following files in `hamideih_data/`:

- **`train.csv`** — Full UCI Superconductor dataset (21,263 samples, 81 composition-derived features + critical temperature). Used for UCI/SuperCon XGBoost baseline.
- **`unique_m.csv`** — Deduplicated version keyed by chemical formula (~12,000 unique compositions). Used for composition-score analysis.

Source: [UCI Machine Learning Repository — Superconductivity Data](https://archive.ics.uci.edu/dataset/464/superconductivty+data)

Reference: Hamidieh, K. (2018). A data-driven statistical model for predicting the critical temperature of a superconductor. *Computational Materials Science*, 154, 346-354.

## 3DSC (Sommer et al. 2023)

Place the following file in `3dsc_data/`:

- **`3DSC_MP_with_MAGPIE.csv`** — 3DSC dataset enriched with MAGPIE descriptors (5,773 samples, 159 structural + MAGPIE features). Generated by running `ml/generate_magpie_features.py` on the base 3DSC_MP dataset.

If starting from the raw 3DSC dataset, first obtain `3DSC_MP.csv` from the source below, then run `python ml/generate_magpie_features.py` to generate MAGPIE features.

Source: [3DSC GitHub Repository](https://github.com/aimat-lab/3DSC)

Reference: Sommer, T., Willa, R., Schmalian, J., & Friederich, P. (2023). 3DSC — a dataset of superconductors including crystal structures. *Scientific Data*, 10(1), 816.
